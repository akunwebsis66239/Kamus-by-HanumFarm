# Kamus Hanum_Farm — PWA Offline

Aplikasi kamus Bahasa Inggris ↔ Bahasa Indonesia yang bisa dipasang di HP dan digunakan offline.

## Upload ke GitHub Pages
1. Buat repository baru di GitHub.
2. Upload SEMUA isi folder ZIP ini (bukan folder luarnya).
3. Masuk **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu **Save**.
6. Buka alamat Pages yang diberikan GitHub melalui Chrome Android.
7. Pilih **Install app / Tambahkan ke layar utama**.

## Catatan
- Kamus tersimpan di `data/dictionary.json`, jadi tidak membutuhkan internet/API.
- Pelafalan memakai fitur speech synthesis browser; ketersediaannya dapat berbeda antar perangkat/browser.
- Foto footer berasal dari foto yang diberikan pemilik aplikasi.
